# MAURIC ecosystem planning foundation
This package links the agent registry to Stephen's task, the reusable studio, release downloads and evidence gates.
Status: read-only planning prototype; not registered in an MCP host and no external adapters are connected.

Osayi guides. Marius routes. Knowledge, SharePoint, systems, banking, delivery, release and assurance responsibilities are declared in agent-registry.json. Declaration is not a running agent or access grant.

Run with Python 3 using mauric_mcp.py as a stdio subprocess from a compatible MCP host. This foundation deliberately implements the legacy 2025-06-18 initialize lifecycle. It does not claim the newer 2026 protocol or universal-client compatibility. No dependencies, listener port, shell tool, network request or provider action are present.

Tools: mauric_agents, mauric_route_task, mauric_release_contract.
Routes are plans only. SharePoint profile access was confirmed through the ChatGPT connection. Site/library scope is not tested, and this local MCP server is not bound to that connector. No runtime can acquire Microsoft permissions from this registry. Banking and delivery remain simulations. Never place credentials or customer records in this public package.
